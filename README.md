## 🚀 Project Overview
এই প্রজেক্টটি একটি ফার্নিচার শপ ওয়েবসাইট — যেখানে ব্যবহারকারী প্রোডাক্ট ব্রাউজ করতে পারবে, প্রোডাক্ট ডিটেইল দেখতে পারবে, কার্টে পণ্য যোগ করতে পারবে এবং Checkout বা Shop Now ফ্লো অনুসরণ করতে পারবে।  
Website টি mobile-first ডিজাইন, SEO-friendly meta tags, ও ক্রিস্প UI/UX সহ তৈরি করা হয়েছে।

---

## ✨ Features
- হোম পেজ — হিরো সেকশন, ক্যাটাগরি, বেস্টসেলার  
- প্রোডাক্ট লিস্টিং ও প্রোডাক্ট ডিটেইল পেজ  
- Add to Cart (একটি প্রোডাক্ট একবারেই যোগ করা যায়)  
- Navbar-তে লাইভ Cart count  
- Cart page — image, name, price, Shop Now & Delete অপশন  
- Responsive layout (mobile, tablet, desktop)  
- SEO meta tags, sitemap.xml ও robots.txt অনুমোদনযোগ্য ফাইল  
- সহজে Netlify/Vercel-এ deploy করার উপযোগী

---

## 🧰 Tech Stack
- Frontend: React or plain HTML/CSS/JS 
- State management: (optional) Redux Toolkit + React-Redux  
- Styling: Tailwind CSS / CSS Modules / plain CSS  
- Bundler: Vite / Create React App / Next.js   
- Deployment: Netlify / Vercel / GitHub Pages
